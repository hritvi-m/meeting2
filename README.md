# meeting2
Put these two files in this folder (same names, case-sensitive):

  NotoSansDevanagari-Regular.ttf
  NotoSansDevanagari-Bold.ttf

Download (free, OFL license):
https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari

Click "Get font" -> "Download all", unzip, and grab the two static weights
above from the static/ folder (rename if needed to match exactly).

Without these files, the app falls back to Helvetica and Hindi/Devanagari
text in the MoM PDF will show blank/missing characters, same as before.
